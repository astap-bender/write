# GeoArt - Художественная геолокация

## Описание проекта

**GeoArt** — это инновационное приложение для создания художественных работ путём отслеживания пути движения пользователя с помощью геолокации. Превратите ваше путешествие в художественное произведение!

## Основные возможности

### 🎯 Система отслеживания геолокации
- Запись пути движения пользователя в реальном времени
- Высокоточное определение местоположения
- Автоматическое сохранение координат при включённом режиме записи

### 🗺️ Интерактивная карта
- Визуализация траектории движения на интерактивной карте
- Отображение начальной и конечной точек маршрута
- Оптимальное позиционирование карты для просмотра всего пути

### 🎨 Функция рисования
- Рисование поверх траектории с помощью мыши
- Выбор цвета рисования (полная палитра RGB)
- Регулировка размера кисти (1-20 пиксела)
- Плавное рисование с отслеживанием движения мыши

### 📝 Текстовые заметки
- Добавление названия работы
- Опциональное описание художественного произведения
- Привязка к конкретной дате создания

### 📅 Ежедневное сохранение
- Автоматическое сохранение работ с датой создания
- Организация работ по датам в профиле
- Полная история творчества пользователя

### 🌟 Социальные функции

#### 🔥 Расширенная галерея (Feed)
- **Полноразмерные карточки работ** с детальной информацией
- **3 режима сортировки**:
  - По рейтингу (стандартная сортировка)
  - Самые горячие (по уровню вовлечённости)
  - По дате (новые работы сверху)
- **Визуальные индикаторы**:
  - Значок 🔥 для популярных работ (5+ лайков/дизлайков/комментариев)
  - Цветные бэджи рейтинга (зелёный/красный)
- **Инфографика вовлечённости**:
  - Счётчики лайков, дизлайков, комментариев
  - Визуальная полоса уровня вовлечённости
  - Цветные блоки для каждого типа взаимодействия
- **Спецэффекты при оценке**:
  - Анимированные эмодзи (❤️/👎) при лайке/дизлайке
  - Парящая анимация с затуханием
  - Визуальная обратная связь при клике
- **Live-обновление ленты**:
  - Автоматическое обновление рейтинга в реальном времени (каждую секунду)
  - Синхронизация изменений между вкладками
  - Плавная переиндексация при изменении рейтинга
- **Бесконечный скролл**:
  - Автоматическая подгрузка новых работ при прокрутке
  - Кнопка "Загрузить ещё" для явной загрузки

#### Система оценки
- **Лайки**: повышают рейтинг работы (вес +2)
- **Дизлайки**: понижают рейтинг работы (вес -3)
- Динамический рейтинг: (лайки × 2) - (дизлайки × 3)
- Визуальный тренд: цветовая индикация роста/падения

#### Рейтинговая система
- Работы с большим количеством лайков поднимаются в топ
- Работы с дизлайками опускаются
- Визуализация текущего рейтинга на каждой карточке
- Учёт комментариев в расчёте популярности

### 👤 Профиль пользователя
- Архив всех созданных работ, организованный по датам
- Статистика: количество работ, лайков и комментариев
- Быстрый доступ к истории творчества

### 🔐 Аутентификация
- Простая регистрация с использованием имени и email
- Локальное хранилище пользовательских данных
- Сохранение сессии между посещениями

### 🎮 Панель управления
- **Запись**: начало и остановка отслеживания геолокации
- **Рисование**: переключение режима рисования во время записи
- **Сохранение**: сохранение готовой работы с названием и описанием
- **Удаление**: отмена незавершённой работы

## Архитектура

### Технический стек
- **React 19** с TypeScript для типобезопасности
- **Leaflet** для интерактивных карт (OpenStreetMap)
- **Vite** для быстрой разработки и сборки
- **Tailwind CSS** для современного дизайна
- **shadcn/ui** для готовых компонентов интерфейса
- **date-fns** для форматирования временных меток

### Структура данных

```typescript
// Геолокация
interface GeoLocation {
  latitude: number
  longitude: number
  timestamp: number
  accuracy?: number
}

// Точка рисования
interface DrawingPoint {
  x: number
  y: number
  color: string
  size: number
}

// Художественная работа
interface Artwork {
  id: string
  userId: string
  userName: string
  title: string
  description?: string
  path: GeoLocation[]           // Траектория
  drawings: DrawingPoint[]      // Штрихи
  createdAt: number
  likes: number
  dislikes: number
  rating: number
  dateKey: string              // YYYY-MM-DD
  commentCount: number
}

// Пользователь
interface User {
  id: string
  name: string
  email: string
  createdAt: number
}
```

### Хранилище данных
- Использует браузерное хранилище **localStorage**
- Все данные работ, оценок и профилей хранятся локально
- Автоматическое сохранение при создании/редактировании
- Polling каждую секунду для real-time обновлений

## Использование

### Создание новой работы

1. **Авторизация**: введите имя и email
2. **Запись**: нажмите "Начать запись" на главной странице
3. **Рисование** (опционально):
   - Нажмите "Рисование"
   - Выберите цвет и размер кисти
   - Рисуйте на карте
4. **Сохранение**:
   - Нажмите "Остановить запись"
   - Введите название работы
   - Добавьте описание (опционально)
   - Нажмите "Сохранить работу"

### Просмотр галереи

1. Перейдите на вкладку "Галерея"
2. Выберите режим сортировки:
   - **По рейтингу**: работы отсортированы от высокого к низкому рейтингу
   - **Самые горячие**: работы с наибольшей активностью (лайки + дизлайки + комментарии)
   - **По дате**: новые работы сверху
3. Нажмите на работу для подробного просмотра
4. Оцените работу лайком или дизлайком (с анимацией)
5. Видите в реальном времени, как меняется рейтинг других работ

### Управление профилем

1. Перейдите на вкладку "Профиль"
2. Просмотрите статистику
3. Навигируйте по работам, организованным по датам
4. Используйте кнопку "Выход" для смены аккаунта

## Алгоритмы

### Ранжирование работ

```
основной_рейтинг = (количество_лайков × 2) - (количество_дизлайков × 3)
тренд_оценка = (лайки × 3) + (комментарии × 2) - (дизлайки × 2)
```

- **По рейтингу**: сортировка по основному рейтингу
- **Самые горячие**: сортировка по оценке тренда (более динамичная)
- **По дате**: хронологический порядок

### Интерпретация оценок
- Рейтинг > 0: работа нравится сообществу (зелёный цвет)
- Рейтинг < 0: работа критикуется (красный цвет)
- Рейтинг = 0: нейтральная оценка (серый цвет)

### Популярность работ
- Работа считается популярной, если сумма (лайки + дизлайки + комментарии) >= 5
- Популярные работы отмечены значком 🔥 и подсвечиваются
